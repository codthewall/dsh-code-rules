# dsh-code-rules

A DeepSeek Harness plugin that generates, injects, and maintains a project's code-constraint
document (`CODE-RULES.md`). Status: pre-implementation.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `codthewall/dsh-code-rules`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles map 1:1 to labels of the same name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root and decisions under `docs/adr/`. See `docs/agents/domain.md`.
